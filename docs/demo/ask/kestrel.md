# Project Kestrel: pilot summary

## Overview
Project Kestrel is a river-monitoring pilot run by the Kuching office. It started in
March 2025 and is led by Nadia Rahman.

## Sensors
The pilot uses 42 water-level sensors placed along the Sarawak River. Each sensor
uploads a reading every 15 minutes to a central dashboard. A reading above 4.5 metres
raises a flood alert to the duty officer by SMS.

## Budget
The pilot budget is RM 380,000 for two years. Any change above RM 20,000 must be
approved by the steering committee, which meets on the first Monday of each month.

## Next phase
If the pilot meets its targets, a second phase in 2027 would extend coverage to the
Rajang River with another 60 sensors.
