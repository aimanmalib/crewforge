# SKP2101 Pengajian Malaysia — Tugasan Individu

Pensyarah: Encik Hafiz Rahman

Tulis sebuah esei sebanyak 1,000 patah perkataan bertajuk:
"Kesan media sosial terhadap penglibatan politik belia di Malaysia selepas pelaksanaan Undi18."

- Gunakan gaya rujukan APA edisi ke-7.
- Sekurang-kurangnya empat sumber ilmiah.
- Esei mesti mempunyai pengenalan, isi dan kesimpulan.

Rubrik pemarkahan
- Kefahaman isu (30%)
- Hujah dan bukti (30%)
- Struktur esei (20%)
- Bahasa dan rujukan (20%)
